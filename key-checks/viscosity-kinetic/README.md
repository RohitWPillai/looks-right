# Viscosity key check: the kinetic part of the stress (9 Oct 2026)

**Why.** The key said the viscosity Follow run (id A34) is trusted. Auditors in Exp 1 objected that the course input
`viscosity.in` computes the shear stress with `compute stress/atom NULL pair`, which keeps only the pair (force) part
and leaves out the kinetic part. No `-var` switch can test that, so this check was run outside the experiment.

**What.** `sim/` is the course's Day 1 channel with 12 lines added to `viscosity/viscosity.in` after line 71 (marked
KEY CHECK); no original line is changed (compare with `cases/viscosity-base/viscosity/viscosity.in`). They write
`day1_stress_kinetic.dat`: pair p_xz (as before), kinetic p_xz with the flow speed removed per z-slice
(`compute temp/profile`), and the kinetic xx and zz parts. Runs: seeds 11, 22, 33 (`run-s<seed>/`), 8 MPI ranks,
LAMMPS 22 Jul 2025 Update 5. Control `control-s11/`: the same lines with no bias removal.

**Result** (`SUMMARY.md`, regenerated by `python3 summarise.py`):

| seed | pair p_xz | kinetic p_xz | kinetic / pair | kinetic xx / zz | fluid T from zz |
|---|---|---|---|---|---|
| 11 | -0.0627 ± 0.0029 | -0.00725 ± 0.00070 | 11.6% | 0.992 | 1.093 |
| 22 | -0.0610 ± 0.0029 | -0.00754 ± 0.00051 | 12.4% | 0.992 | 1.090 |
| 33 | -0.0635 ± 0.0029 | -0.00793 ± 0.00043 | 12.5% | 0.990 | 1.099 |

± is the standard error from ten blocks of the recorded series.

The kinetic part is about 12% of the pair part and has the same sign, so the course reports a viscosity about 11%
below the value with both parts. Kinetic xx and zz agree to 1% (the flow speed is removed correctly), and the fluid
temperature from them matches the temperature profile the run writes.

**The pair series is not identical to the earlier runs** ("NOT SAME" in `SUMMARY.md`; the earlier runs' pair
series are in `replica-s<seed>/`). Cause: `temp/profile` subtracts and restores the flow speed in each atom's
velocity, and the rounding perturbs the trajectory. The control run, without the bias, reproduces the earlier seed-11
pair series exactly. The new runs' pair means agree with the earlier ones within their block errors.

**Not checked here.** The input also fixes the fluid height used for the volume at 18.918 sigma; whether that
calibration holds was not checked here.
